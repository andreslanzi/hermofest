# HERMOFEST

Landing page inmersiva para el evento — techno desde el sótano.

Una sola página estática (`index.html`, sin build ni dependencias): túnel de partículas en canvas, tipografía que se ensambla en puntos al scrollear, glitch brutalista y los nodos **Location / Line-Up / Schedule** que se decodifican al interactuar. Mobile-first.

## Correr localmente

Abrir `index.html` en el navegador, o servirlo con cualquier server estático:

```bash
npx serve .
```

## Stack

HTML + CSS + JS vanilla. Fuentes: BBH Bartle, Michroma, Smooch Sans y Source Code Pro (Google Fonts).
